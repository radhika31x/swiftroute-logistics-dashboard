# SwiftRoute Logistics Dashboard

## Overview
SwiftRoute Logistics Dashboard is a data analytics project developed using Microsoft Power BI to analyze logistics operations and delivery performance.

## Objectives
- Analyze shipment and delivery performance.
- Track key logistics KPIs.
- Identify operational trends and patterns.
- Present business insights through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Data Analytics
- Data Visualization

## Project Structure
- `Dashboard/` – Power BI dashboard files
- `Screenshots/` – Dashboard preview images
- `SwiftRoute_Dashboard.pdf` – Dashboard report
